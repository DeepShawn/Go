弈境 · 围棋

五档 KataGo 人机、同屏双人、4 位房间码联机。支持提子、禁入点、简单劫、停一手、贴目、2–9 子标准让子与终局死子标记。

让子局先放置黑方让子，再由白方先行。AI 使用浏览器内 KataGo 神经网络；采用低延迟 Policy/Value 批量搜索。
首次使用需联网下载约 75 MB 模型，之后优先从浏览器缓存加载。
4 位房间码通过 PeerJS Cloud 做信令交换，连接建立后棋步通过 WebRTC DataChannel 点对点传输。同一局域网通常可直连；复杂 NAT 可能需要 TURN。

规则说明

基本：黑先白后；无气棋块被提走；禁止自杀；采用简单劫，不能立即还原上一手之前的局面。

让子：支持 2–9 子固定让子。9 路按三线星位，13/19 路按四线星位排列；让子放置完成后白方先行。传统让子局通常使用较低贴目，本页允许自由设置。

终局：连续两次停一手进入数子。点击棋块可标记死子；按中国面积法计算盘上活子与围空，白方再加贴目。

KataGo：浏览器内加载 KataGo B28 ONNX 神经网络，使用 Web Worker 执行推理。新版只请求 Policy 与 Value 两个输出头，并用批量候选评估代替逐节点串行搜索；五档难度通过随机度、候选宽度和浅层应手评估控制。优先 WebGPU，不支持时自动回退 WASM。模型首次联网下载后缓存在浏览器中。

联机：房主执黑、访客执白；房主决定棋盘、贴目和让子设置。
