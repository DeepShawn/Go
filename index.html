规则说明

基本：黑先白后；无气棋块被提走；禁止自杀；采用简单劫，不能立即还原上一手之前的局面。

让子：支持 2–9 子固定让子。9 路按三线星位，13/19 路按四线星位排列；让子放置完成后白方先行。传统让子局通常使用较低贴目，本页允许自由设置。

坐标与确认：棋盘顶部显示字母坐标、左侧显示数字坐标，字母按围棋惯例跳过 I。点击交叉点后先预览并在右侧显示坐标，确认后才正式落子。

棋谱与缓存：对局会自动保存到浏览器本机缓存；检测到有效缓存时，主页会自动出现“恢复上次棋局”按钮，没有缓存时该按钮自动隐藏。也可手动保存/恢复/清除，并支持上传 SGF 主变化、导出当前棋盘和完整记录。

棋盘分析：可随时调用浏览器 b6c96 或 HTTP KataGo 分析当前局面，显示候选着法、策略概率/visits、胜率、领先与 PV，并在棋盘标记前 6 个候选点。

数目：点击“数目”默认直接调用浏览器内 KataGo b6c96 的 ownership/value 输出，不需要本机 API；也可在菜单中切换到 HTTP Analysis API，读取搜索后的 ownership、winrate 与 rootInfo.scoreLead。棋盘会覆盖显示 KataGo 预测的黑白归属。该结果是 AI 形势/终局预测，不等同于赛事裁判裁决。

终局：连续两次停一手进入结算；人机模式也可随时“中断结算”。点击棋块标记死子后，按菜单选择的日韩数目或中国数子规则计算。

KataGo：可选三种引擎：浏览器内 b6c96 / b10c128 快速 AI、普通 KataGo HTTP 搜索，以及需要 Human SL 模型的 HumanSL K/D 人类风格模式。浏览器 AI 和普通 HTTP 搜索只提供强度等级，不再把搜索量硬换算为 K/D。若需要 K/D，请使用 HumanSL 模式：服务器需加载 KataGo Human SL 模型，并通过 humanSLProfile=rank_20k…rank_9d 生成对应人类风格着法。

联机：房主执黑、访客执白；房主决定棋盘、贴目和让子设置。
